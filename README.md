# Web Highlights Vault Personal — public information

This repository contains only the static application homepage, privacy policy, stylesheet, and public icon for Web Highlights Vault Personal.

- Homepage: https://cheney-chenen.github.io/web-highlights-vault-info/
- Privacy policy: https://cheney-chenen.github.io/web-highlights-vault-info/privacy.html

It does not contain the browser extension implementation, saved highlights, notes, backups, account identifiers, or OAuth tokens. There is no website login, data upload endpoint, analytics script, or application backend.

GitHub Pages publishes the `main` branch at its root. `.nojekyll` keeps this a buildless static site. Use the repository's Issues for support without attaching private reading data or credentials.
